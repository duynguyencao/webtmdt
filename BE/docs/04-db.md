# 04) Kết nối MongoDB (`db/dbConnect.js`)

File: `BE/db/dbConnect.js`

## File này dùng để làm gì?

BE cần MongoDB để lưu:

- sản phẩm
- user
- giỏ hàng
- đơn hàng
- coupon
- review
- log PayOS
- cấu hình trang chủ

`connectDB()` là hàm được gọi trong `index.js` để nối DB trước khi phục vụ API.

## Các dòng quan trọng (giải thích theo đúng code)

- `import mongoose from 'mongoose'`
  - Mongoose là “cầu nối” để code JavaScript làm việc với MongoDB.

- `defaultUri = 'mongodb://127.0.0.1:27017/caulong-shop'`
  - Nếu bạn chưa set `MONGODB_URI` thì BE dùng DB local mặc định.

- `export async function connectDB() { ... }`
  - Đây là hàm kết nối chính.

Trong `connectDB()`:

- `const uri = process.env.MONGODB_URI || defaultUri`
  - Ưu tiên dùng cấu hình trong `.env`. Nếu không có thì dùng default.

- `const isAtlas = uri.includes('mongodb.net')`
  - Chỉ để log “Atlas” hay “local”.

- `await mongoose.connect(uri)`
  - Thực hiện kết nối DB.

- Nếu kết nối OK:
  - `console.log('Đã kết nối MongoDB:', mongoose.connection.name, ...)`
  - Giúp bạn biết đang kết nối vào DB tên gì.

- Nếu lỗi:
  - log lỗi
  - `throw err` để `index.js` biết là DB chưa lên.
