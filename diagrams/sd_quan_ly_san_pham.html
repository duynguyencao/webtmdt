Sơ đồ tuần tự: Quản lý Sản phẩm (Admin)

1. Xem danh sách sản phẩm

sequenceDiagram actor AD as Admin participant UI as Màn hình QL SP
(Boundary) participant CTRL as BĐK Sản phẩm
(Control) participant EP as Sản phẩm
(Entity) AD->>UI: Truy cập trang quản lý sản phẩm UI->>CTRL: Yêu cầu danh sách SP (bộ lọc, phân trang) activate CTRL CTRL->>EP: Truy vấn danh sách SP đang hoạt động activate EP EP-->>CTRL: Trả về danh sách SP deactivate EP CTRL-->>UI: Trả về dữ liệu đã xử lý deactivate CTRL UI-->>AD: Hiển thị danh sách sản phẩm

2. Thêm sản phẩm mới

sequenceDiagram actor AD as Admin participant UI as Màn hình QL SP
(Boundary) participant CTRL as BĐK Sản phẩm
(Control) participant EP as Sản phẩm
(Entity) AD->>UI: Nhập thông tin SP, bấm Thêm UI->>CTRL: Gửi yêu cầu thêm SP (tên, giá, ảnh, tồn kho) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>CTRL: Kiểm tra và chuẩn hóa dữ liệu CTRL->>EP: Lấy mã SP lớn nhất hiện tại activate EP EP-->>CTRL: Mã SP lớn nhất deactivate EP CTRL->>EP: Tạo sản phẩm mới (mã = max + 1) activate EP EP-->>CTRL: Xác nhận tạo thành công deactivate EP CTRL-->>UI: Trả về thông tin SP đã tạo deactivate CTRL UI-->>AD: Hiển thị thông báo thêm thành công

3. Cập nhật sản phẩm

sequenceDiagram actor AD as Admin participant UI as Màn hình QL SP
(Boundary) participant CTRL as BĐK Sản phẩm
(Control) participant EP as Sản phẩm
(Entity) AD->>UI: Sửa thông tin SP, bấm Lưu UI->>CTRL: Gửi yêu cầu cập nhật (mã SP, dữ liệu mới) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>CTRL: Chuẩn hóa dữ liệu sản phẩm CTRL->>EP: Cập nhật sản phẩm theo mã SP activate EP EP-->>CTRL: Trả về SP đã cập nhật deactivate EP alt Không tìm thấy CTRL-->>UI: Lỗi: Không tìm thấy sản phẩm UI-->>AD: Hiển thị thông báo lỗi else Thành công CTRL-->>UI: Trả về kết quả cập nhật UI-->>AD: Hiển thị SP đã cập nhật end deactivate CTRL

4. Xóa mềm sản phẩm

sequenceDiagram actor AD as Admin participant UI as Màn hình QL SP
(Boundary) participant CTRL as BĐK Sản phẩm
(Control) participant EP as Sản phẩm
(Entity) AD->>UI: Bấm Xóa sản phẩm UI->>CTRL: Gửi yêu cầu xóa SP (mã SP) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>EP: Đánh dấu xóa mềm sản phẩm activate EP EP-->>CTRL: Xác nhận đã xóa mềm deactivate EP alt Không tìm thấy CTRL-->>UI: Lỗi: Không tìm thấy sản phẩm UI-->>AD: Hiển thị thông báo lỗi else Thành công CTRL-->>UI: Trả về kết quả xóa UI-->>AD: Hiển thị thông báo đã xóa end deactivate CTRL Note over EP: Xóa mềm: SP vẫn lưu trong CSDL để giữ lịch sử đơn hàng
