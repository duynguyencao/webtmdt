Sơ đồ tuần tự: Quản lý Đơn hàng (Admin)

1. Xem tất cả đơn hàng

sequenceDiagram actor AD as Admin participant UI as Màn hình QL ĐH
(Boundary) participant CTRL as BĐK Đơn hàng
(Control) participant EO as Đơn hàng
(Entity) AD->>UI: Truy cập trang quản lý đơn hàng UI->>CTRL: Yêu cầu danh sách ĐH (bộ lọc, phân trang) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>EO: Truy vấn danh sách đơn hàng activate EO EO-->>CTRL: Trả về danh sách đơn hàng deactivate EO CTRL-->>UI: Trả về dữ liệu đã xử lý deactivate CTRL UI-->>AD: Hiển thị danh sách đơn hàng

2. Xem chi tiết đơn hàng

sequenceDiagram actor AD as Admin participant UI as Màn hình QL ĐH
(Boundary) participant CTRL as BĐK Đơn hàng
(Control) participant EO as Đơn hàng
(Entity) AD->>UI: Chọn đơn hàng để xem chi tiết UI->>CTRL: Yêu cầu chi tiết ĐH (mã đơn) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>EO: Truy vấn đơn hàng theo mã đơn activate EO EO-->>CTRL: Trả về thông tin đơn hàng deactivate EO alt Không tìm thấy CTRL-->>UI: Lỗi: Không tìm thấy đơn hàng UI-->>AD: Hiển thị thông báo lỗi else Tìm thấy CTRL-->>UI: Trả về chi tiết đơn hàng UI-->>AD: Hiển thị chi tiết đơn hàng end deactivate CTRL

3. Xác nhận đơn hàng COD

sequenceDiagram actor AD as Admin participant UI as Màn hình QL ĐH
(Boundary) participant CTRL as BĐK Đơn hàng
(Control) participant EO as Đơn hàng
(Entity) AD->>UI: Bấm Xác nhận đơn hàng UI->>CTRL: Gửi yêu cầu xác nhận đơn (mã đơn) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>EO: Truy vấn đơn hàng theo mã đơn activate EO EO-->>CTRL: Trả về thông tin đơn hàng deactivate EO CTRL->>CTRL: Kiểm tra trạng thái và phương thức thanh toán alt Trạng thái không hợp lệ hoặc không phải COD CTRL-->>UI: Lỗi: Không thể xác nhận đơn này UI-->>AD: Hiển thị thông báo lỗi else Hợp lệ CTRL->>EO: Cập nhật trạng thái thành Đã xác nhận activate EO EO-->>CTRL: Xác nhận cập nhật thành công deactivate EO CTRL-->>UI: Trả về kết quả xác nhận UI-->>AD: Hiển thị đơn hàng đã xác nhận end deactivate CTRL

4. Hủy đơn hàng (hoàn kho + hoàn coupon)

sequenceDiagram actor AD as Admin participant UI as Màn hình QL ĐH
(Boundary) participant CTRL as BĐK Đơn hàng
(Control) participant EO as Đơn hàng
(Entity) participant EP as Sản phẩm
(Entity) participant EC as Mã giảm giá
(Entity) AD->>UI: Bấm Hủy đơn hàng UI->>CTRL: Gửi yêu cầu hủy đơn (mã đơn) activate CTRL CTRL->>CTRL: Xác thực quyền Admin CTRL->>EO: Truy vấn đơn hàng theo mã đơn activate EO EO-->>CTRL: Trả về thông tin đơn hàng deactivate EO CTRL->>CTRL: Kiểm tra trạng thái cho phép hủy alt Không cho phép hủy CTRL-->>UI: Lỗi: Không thể hủy đơn ở trạng thái này UI-->>AD: Hiển thị thông báo lỗi else Hợp lệ opt Đơn đã sử dụng mã giảm giá CTRL->>EC: Truy vấn mã giảm giá activate EC EC-->>CTRL: Thông tin mã giảm giá deactivate EC CTRL->>EC: Hoàn lại lượt sử dụng activate EC EC-->>CTRL: Xác nhận hoàn thành công deactivate EC end loop Hoàn kho cho từng SP trong đơn CTRL->>EP: Hoàn lại số lượng tồn kho activate EP EP-->>CTRL: Xác nhận đã hoàn kho deactivate EP end CTRL->>EO: Cập nhật trạng thái thành Đã hủy activate EO EO-->>CTRL: Xác nhận cập nhật thành công deactivate EO CTRL-->>UI: Đã hủy đơn và hoàn tồn kho UI-->>AD: Hiển thị thông báo đã hủy đơn end deactivate CTRL
